1. Core Module Review & Conceptual Foundations

1.1 The Aggregate Query Problem & AQP Motivation

Exact aggregate queries (`COUNT`, `SUM`, `AVG`, `PERCENTILE`) over massive analytical tables ($N = 10^{12}$ rows) present a fundamental tractability challenge for modern data infrastructure. In interactive analytical workloads, business analysts exploring dashboards require sub-second or low-latency responses when adjusting filter predicates. However, computing an exact aggregate requires scanning every row that satisfies the query condition.

Traditional indexing and hardware-scaling paradigms fail to solve this problem for ad hoc analytical workloads:

- **Failure of Precomputed Inverted Indexes**: Precomputed structures like inverted indexes excel at term lookups (as used in search engines), but they cannot precompute index structures for every possible ad hoc combination of filter predicates and continuous attribute ranges.
- **Limitations of Parallel Execution**: Distributed full table scans across large clusters reduce runtime, but processing a trillion rows still requires seconds to minutes. Parallelism increases throughput, but it cannot overcome the physical disk I/O and network transfer overhead required to touch every row within interactive latency budgets.

This intractability motivates **Approximate Query Processing (AQP)**. AQP adopts the statistical philosophy attributed to John Tukey:

_"It is better to have an approximate answer to the right question than an exact answer to the wrong one."_

The core paradigm of AQP is to trade a small, controlled, and mathematically quantified error for a massive reduction in query latency. Rather than executing an expensive $O(N)$ full table scan, AQP evaluates queries over a subset of data or metadata, reducing computational complexity to $O(n)$ where $n \ll N$.

Modern systems employ two primary strategies to achieve this trade-off:

1. **Sampling**: Compute aggregates over a small random subset of rows and apply statistical concentration bounds to quantify error.
2. **Data-Skipping**: Use lightweight block metadata to eliminate non-matching data blocks entirely without reading raw rows—an exact technique that introduces zero error.

1.2 Sampling Mechanics, Unbiasedness, and Error Behavior

Sampling serves as the foundational Primitive of AQP. Given a population of size $N$ with an unknown population mean $\mu$, a simple random sample of $n$ values drawn uniformly ($x_1, x_2, \dots, x_n$) yields the **sample mean** estimator:

$$\bar{x} = \frac{1}{n} \sum_{i=1}^{n} x_i$$

Unbiasedness of Estimators

By the linearity of expectation, the sample mean $\bar{x}$ is an **unbiased estimator** of the population mean $\mu$:

$$E[\bar{x}] = E\left[\frac{1}{n}\sum_{i=1}^n x_i\right] = \frac{1}{n}\sum_{i=1}^n E[x_i] = \frac{1}{n} \cdot n\mu = \mu$$

Unbiasedness guarantees that across repeated random draws, the expected value of $\bar{x}$ equals the true population parameter $\mu$, exhibiting no systematic over- or under-estimation. Other primary relational aggregates are derived directly from $\bar{x}$:

- $\text{SUM}$ **Estimation**: Scaled directly by population size: $\hat{\text{SUM}} = N \cdot \bar{x}$.
- $\text{COUNT}$ **Estimation**: Estimated by scaling the sample fraction $\hat{p}$ that satisfies the query condition: $\hat{\text{COUNT}} = N \cdot \hat{p}$.

Variance and Standard Error

While unbiasedness ensures accuracy on average, single sample draws deviate from $\mu$. The typical magnitude of this discrepancy is governed by the **Standard Error (SE)** of the mean. For independent draws with population variance $\sigma^2$ (or sample standard deviation $s$ when $\sigma$ is unknown):

$$SE = \frac{\sigma}{\sqrt{n}}$$

When sampling without replacement from a finite population $N$, the exact variance includes the **Finite-Population Correction** factor $\frac{N-n}{N-1}$:

$$\text{Var}(\bar{x}) = \frac{\sigma^2}{n} \left( \frac{N-n}{N-1} \right)$$

In the big data regime ($n \ll N$), this correction factor approaches $1$, simplifying the standard error back to $\sigma / \sqrt{n}$.

|Sample Size ($n$)|Standard Error ($SE$) ($\sigma = 1.0$)|Relative Cost|
|---|---|---|
|100|0.1000|$1\times$|
|400|0.0500|$4\times$|
|1,600|0.0250|$16\times$|
|10,000|0.0100|$100\times$|

The Law of Diminishing Returns and Scaling Properties

1. **Inverse Square Root Scaling**: Because $SE \propto 1/\sqrt{n}$, standard error decreases at a diminishing rate. Achieving a 10-fold reduction in error requires expanding the sample size $n$ by a factor of $10^2 = 100$.
2. **Independence from Population Size** $N$: The standard error formula depends exclusively on sample size $n$ and attribute variance $\sigma^2$; total table size $N$ does not appear. Consequently, achieving a target absolute error bound costs the exact same sample size $n$ whether $N = 10^6$ or $N = 10^{12}$. This property enables sampling-based AQP to scale to massive datasets.

Streaming Analytics & Reservoir Sampling

When processing unbounded data streams, the total population size $N$ is unknown in advance, making naive random sampling impossible. **Reservoir Sampling** solves this by maintaining a fixed-size sample (a "reservoir") of size $k$ over an streaming dataset:

1. Fill the reservoir with the first $k$ items from the stream.
2. For each subsequent item arriving at index $i$ ($i > k$), admit the item into the reservoir with probability $k/i$. If admitted, replace a randomly chosen item in the reservoir (probability $1/k$).

_Proof of Uniformity_: At step $i$, item $i$ enters the reservoir with probability $k/i$. At any subsequent step $j$ ($j > i$), the probability that the item is _not_ evicted is $1 - \left(\frac{k}{j} \cdot \frac{1}{k}\right) = \frac{j-1}{j}$. The overall survival probability from step $i+1$ to step $n$ forms a telescoping product:

$$P(\text{Item } i \text{ in reservoir at step } n) = \frac{k}{i} \times \prod_{j=i+1}^{n} \frac{j-1}{j} = \frac{k}{i} \times \left( \frac{i}{i+1} \times \frac{i+1}{i+2} \times \dots \times \frac{n-1}{n} \right) = \frac{k}{n}$$

Thus, every item observed in the stream maintains an equal, uniform probability $k/n$ of remaining in the sample at step $n$.

Stratified Sampling for Skewed Data

Simple random sampling assumes a homogeneous population. For power-law or highly skewed distributions (e.g., transaction tables where a few large enterprise purchases account for most total revenue), uniform sampling risks missing rare, high-value rows entirely. **Stratified Sampling** partitions the population into homogeneous subgroups (strata) based on known attribute bounds or categories and samples each stratum independently. This guarantees representation of rare, high-value strata and eliminates between-group variance from the standard error calculation.

1.3 Concentration Inequalities: Bounding Error & Confidence Intervals

To transform point estimates into formal system guarantees, AQP engines construct **confidence intervals** at a specified confidence level $1 - \delta$. A confidence interval guarantees that the true parameter $\mu$ falls within the bounded error range $[\bar{x} - \varepsilon, \bar{x} + \varepsilon]$ with probability at least $1 - \delta$:

$$P(|\bar{x} - \mu| \le \varepsilon) \ge 1 - \delta$$

Systems convert variance characteristics into explicit probabilistic guarantees using formal **concentration inequalities**.

Hoeffding's Inequality

Hoeffding's inequality provides a **distribution-free** bound. It requires no knowledge of the underlying distribution shape or variance, assuming only that the random variables are bounded within a known range $[a, b]$:

$$P(|\bar{x} - \mu| \ge \varepsilon) \le 2 \exp\left( -\frac{2n\varepsilon^2}{(b-a)^2} \right)$$

Inverting Hoeffding's inequality yields the error half-width $\varepsilon$ and required sample size $n$:

$$\varepsilon = \sqrt{\frac{\ln(2/\delta)(b-a)^2}{2n}} \quad \iff \quad n = \frac{\ln(2/\delta)(b-a)^2}{2\varepsilon^2}$$

Chebyshev's Inequality

Chebyshev's inequality relies on population or sample variance $\sigma^2$ without requiring a bounded range $[a, b]$:

$$P(|\bar{x} - \mu| \ge \varepsilon) \le \frac{\sigma^2}{n\varepsilon^2}$$

Inverting Chebyshev's inequality yields the error half-width $\varepsilon$ and required sample size $n$:

$$\varepsilon = \sqrt{\frac{\sigma^2}{\delta n}} \quad \iff \quad n = \frac{\sigma^2}{\delta \varepsilon^2}$$

Structural Comparison & Crossover Dynamics

|Dimension / Property|Hoeffding's Inequality|Chebyshev's Inequality|
|---|---|---|
|**Prerequisite Assumptions**|Strictly bounded domain $[a, b]$|Finite variance $\sigma^2$ (bounded range not required)|
|**Scaling in Failure Rate (**$\delta$**)**|Logarithmic: $\varepsilon \propto \sqrt{\ln(2/\delta)}$ (mild penalty for high confidence)|Inverse square root: $\varepsilon \propto \sqrt{1/\delta}$ (steep penalty for high confidence)|
|**Scaling in Sample Size (**$n$**)**|$\varepsilon \propto 1/\sqrt{n}$|$\varepsilon \propto 1/\sqrt{n}$|
|**Comparative Tightness**|Tighter at high confidence levels ($1-\delta$) or wide, uninformative domains|Tighter at moderate confidence levels or when $\sigma \ll (b-a)$|

_Parameter-Dependent Crossover_: The exact point where Hoeffding yields a tighter bound than Chebyshev is strictly parameter-dependent. For instance, given a domain range $b-a = 500$ and standard deviation $\sigma = 80$, Chebyshev provides a tighter bound up to approximately $99\%$ confidence ($\delta = 0.01$), beyond which Hoeffding becomes tighter due to its logarithmic scaling in $\delta$. However, altering $\sigma$ or the range $[a, b]$ shifts this crossover threshold. Query planners compute both bounds dynamically using runtime metadata and report the tighter confidence interval.

The Analytical Bootstrap

While classical empirical bootstrapping requires computationally expensive resampling iterations (e.g., drawing thousands of sample replicates with replacement), the **Analytical Bootstrap** utilizes closed-form equations ($SE = s/\sqrt{n}$, Hoeffding, Chebyshev) to compute sampling distributions instantly. For linear aggregates like `SUM`, `COUNT`, and `AVG`, these formulas provide mathematical bounds without resampling overhead.

Sample Bias: The Fatal Failure Mode

All concentration inequalities rely strictly on the assumption of **independent and identically distributed (i.i.d.) uniform random sampling**.

**Sample Bias** occurs when row selection probabilities are systematically non-uniform (e.g., reading only recently inserted records, scanning contiguous time-series files, or sampling top storage blocks).

Crucially, while **sampling error** shrinks to zero as $O(1/\sqrt{n})$, **sample bias does not shrink as** $n \to \infty$. If bias is present, calculated confidence intervals become invalid regardless of sample size. Mitigating bias requires engineering randomized block selection or auditing sampling code against periodic full-scan totals.

1.4 Data-Skipping via Zone Maps

Unlike sampling, **Data-Skipping** is an **exact** query optimization technique that eliminates physical I/O without introducing any statistical error.

Mechanism of Zone Maps

Analytical storage engines organize rows into contiguous physical blocks (e.g., row groups in columnar formats like Parquet or ORC). A **Zone Map** is lightweight metadata stored alongside data blocks, recording the minimum ($\text{min}$) and maximum ($\text{max}$) values for every column within each block.

Before reading raw block data, the query engine evaluates filter predicates directly against block min/max metadata. If the block range provably cannot contain any rows matching the predicate, the engine **skips** the block entirely.

|Filter Predicate|Skip Block Condition|Scan Block Condition|
|---|---|---|
|$x \ge t$|$\text{max} < t$|$\text{max} \ge t$|
|$x \le t$|$\text{min} > t$|$\text{min} \le t$|
|$a \le x \le b$|$\text{max} < a \text{ OR } \text{min} > b$|$\text{max} \ge a \text{ AND } \text{min} \le b$|
|$x = v$|$v < \text{min} \text{ OR } v > \text{max}$|$\text{min} \le v \le \text{max}$|

The Critical Role of Physical Data Layout

The I/O reduction of zone maps depends heavily on physical data ordering:

- **Clustered / Sorted Layout**: When rows are physically ordered by the filtered column, block min/max ranges are narrow and disjoint. This maximizes block skipping (e.g., skipping 5 out of 8 blocks).
- **Random Layout**: When rows are ordered randomly, every block's min/max range spans almost the entire column domain. As a result, zero blocks can be skipped, forcing a full scan of all blocks.

Data-skipping remains 100% exact under both layouts; physical row ordering affects only execution latency and I/O savings.

1.5 Layered Query Pipelines & Limits of Sampling

The Layered AQP Pipeline

Modern analytical engines integrate data-skipping and statistical sampling into a unified, two-stage execution pipeline:

1. **Stage 1: Exact Data-Skipping (Zone Maps)**: Evaluate block metadata to eliminate non-matching blocks. This stage introduces zero error and reduces the target dataset to candidate blocks.
2. **Stage 2: Bounded Sampling**: Draw a simple random sample from the remaining candidate blocks, evaluate aggregate functions, and apply concentration bounds (Hoeffding/Chebyshev) to yield $\bar{x} \pm \varepsilon$.

Workloads Where Uniform Sampling Fails

Uniform random sampling is mathematically ineffective for specific query classes:

1. **Rare Items & Heavy Skew (Spam Detection)**: For an item appearing $k$ times in $N$ rows, the probability of missing it entirely in a sample of size $n$ is $(1 - n/N)^k$. Uniform sampling frequently fails to detect rare events.
2. **COUNT DISTINCT** **Aggregates**: Scaling sample distinct counts by $N/n$ leads to massive estimation errors. If a dataset has $10^6$ distinct items each repeated 1,000 times, a 1% sample observes almost all $10^6$ distinct items, leading to a scaled estimate $100\times$ too large.
3. **MAX** **/** **MIN** **Aggregates**: Extreme values occur in uniform samples with low probability ($n/N$). Estimating extreme values via uniform sampling yields large error bounds.

Non-sampling workloads rely on specialized, sub-linear space **probabilistic sketches** (e.g., **HyperLogLog** for distinct counting, **Count-Min Sketch** for frequency estimation).

The Three Questions for Approximate Systems

Every approximate computing method must be evaluated against three fundamental core questions:

1. **What is approximated?** (e.g., recall set of items vs. numerical aggregate value).
2. **What exactly is the guarantee?** (e.g., deterministic bound vs. probabilistic confidence interval $1-\delta$).
3. **What can break it?** (e.g., sample bias, severe frequency skew, extreme values, bad hash collisions).

Bridge to Scale-Out Machine Learning (Module 4)

The theoretical principles of AQP directly connect Module 3 (Scaling Classical Tasks) to Module 4 (Scale-Out Learning Systems). In **Mini-Batch Stochastic Gradient Descent (SGD)**, computing the exact model gradient over a massive dataset of size $N$ is intractable.

Instead, SGD treats the mini-batch gradient over $n$ training samples as a **sample mean estimator** of the true per-example gradient. Mini-batch gradients are unbiased and follow the exact same variance scaling law ($SE = \sigma / \sqrt{n}$), establishing concentration inequalities as the core mathematical foundation for distributed optimization.

3. Short-Answer Quiz Key

- **Answer 1**: Aggregate queries evaluate continuous values over dynamic, ad hoc filter predicates rather than static term lookups. Because an analytical engine cannot precompute index structures for every arbitrary predicate combination, evaluating exact aggregates requires full table scans. When operating under strict interactive latency budgets, these full scans become intractable, necessitating approximate processing.
- **Answer 2**: The standard error of the sample mean is governed by the formula $SE = \sigma / \sqrt{n}$, showing that standard error shrinks inversely with the square root of sample size. To reduce $SE$ by a factor of 10, the denominator $\sqrt{n}$ must increase by a factor of 10. Squaring both sides demonstrates that the sample size $n$ must increase by $10^2 = 100$.
- **Answer 3**: Hoeffding's sample size formula $n = \frac{\ln(2/\delta)(b-a)^2}{2\varepsilon^2}$ depends exclusively on the bounded attribute range $[a, b]$, target error $\varepsilon$, and failure probability $\delta$. Because the total population size $N$ does not enter the concentration bound for independent samples, the required sample size depends solely on desired statistical accuracy. This mathematical independence enables sampling-based AQP to scale effortlessly across petabyte-scale datasets.
- **Answer 4**: A bound is "distribution-free" when its validity does not depend on the underlying population possessing a specific probability distribution, such as a Gaussian shape. This property is critical for real-world big data systems because relational attributes like transaction amounts or web clicks exhibit severe skew or non-Gaussian behavior. Hoeffding's inequality guarantees valid bounds for any distribution, provided the data range $[a, b]$ is bounded.
- **Answer 5**: Chebyshev's inequality yields a tighter confidence bound when target confidence levels are moderate or when the attribute variance $\sigma^2$ is small relative to the squared domain range $(b-a)^2$. Because Chebyshev's error scales as $O(1/\sqrt{\delta})$ compared to Hoeffding's logarithmic $O(\sqrt{\ln(1/\delta)})$ scaling, Hoeffding eventually becomes tighter at very high confidence levels. Systems compute both inequalities dynamically using runtime metadata and report the tighter interval.
- **Answer 6**: Sampling error arises from random variation across sample draws and decreases asymptotically at a rate of $O(1/\sqrt{n})$, approaching zero as $n \to \infty$. Conversely, sample bias stems from systematic non-uniform selection frames, such as reading only recently appended records or first storage blocks. Because bias represents a structural flaw in the sampling process, it remains constant and does not shrink regardless of how large $n$ becomes.
- **Answer 7**: Physical row layout dictates how effectively zone maps eliminate I/O work; clustered row layouts yield narrow block ranges that maximize skipped blocks, whereas random layouts cause block ranges to span the entire domain, resulting in zero skipped blocks. However, physical layout affects execution latency only. Because zone maps only drop blocks that provably contain no matching records, the returned answer is guaranteed to be 100% exact regardless of row ordering.
- **Answer 8**: The preliminary zone-map phase is entirely exact and introduces zero error by evaluating strict min/max metadata bounds. Potential error is introduced exclusively during the subsequent random sampling phase performed over the remaining candidate blocks. This sampling error is formally quantified by deriving probabilistic confidence intervals ($\bar{x} \pm \varepsilon$) using concentration inequalities like Hoeffding's or Chebyshev's bounds.
- **Answer 9**: Uniform sampling fails for rare items because their selection probability $n/N$ is extremely low, causing them to be missed entirely in small samples. For `COUNT DISTINCT` queries, scaling observed unique sample items by $N/n$ fails because unique item visibility depends on data repetition skew rather than uniform sample ratios. Consequently, sampling yields massive over- or under-estimations, requiring sub-linear sketching alternatives like HyperLogLog.
- **Answer 10**: Upon encountering the $i$-th item in a stream, Reservoir Sampling admits it into the size-$k$ reservoir with probability $k/i$. The probability that this item survives all subsequent evictions through step $n$ is represented by a telescoping product of survival probabilities. Multiplying the admission probability by the continuous survival probabilities proves that every item resides in the final reservoir with an exact uniform probability of $k/n$.

5. Comprehensive Glossary of Key Terms

|Term|Definition|
|---|---|
|**Approximate Query Processing (AQP)**|A query processing paradigm that trades a small, controlled, and quantified statistical error for a massive reduction in query execution latency.|
|**Population Mean (**$\mu$**)**|The exact average computed over all $N$ rows of a dataset; often unknown or too expensive to compute directly at scale.|
|**Sample Mean (**$\bar{x}$**)**|An unbiased estimator of the population mean computed over a small, uniformly drawn random subset of $n$ values: $\bar{x} = \frac{1}{n} \sum_{i=1}^n x_i$.|
|**Unbiased Estimator**|An estimator whose expected value equals the true population parameter ($E[\bar{x}] = \mu$), exhibiting no systematic over- or under-estimation across repeated samples.|
|**Standard Error (SE)**|The standard deviation of the sample mean estimator, quantifying the typical discrepancy size between $\bar{x}$ and $\mu$; given by $SE = \sigma / \sqrt{n}$.|
|**Finite-Population Correction**|A variance adjustment factor $\frac{N-n}{N-1}$ applied when sampling _without_ replacement from a finite population of size $N$.|
|**Confidence Interval (**$1-\delta$**)**|A probabilistic error bound specifying a range $\bar{x} \pm \varepsilon$ that is guaranteed to enclose the true parameter $\mu$ with probability at least $1-\delta$.|
|**Hoeffding's Inequality**|A distribution-free concentration inequality requiring only a bounded domain $[a, b]$, yielding half-width $\varepsilon = \sqrt{\frac{\ln(2/\delta)(b-a)^2}{2n}}$.|
|**Chebyshev's Inequality**|A variance-based concentration inequality requiring finite variance $\sigma^2$ but no bounded range assumption, yielding half-width $\varepsilon = \sqrt{\frac{\sigma^2}{\delta n}}$.|
|**Sample Bias**|Systematic estimation error caused by non-uniform sampling frames; unlike sampling error, sample bias does _not_ shrink as sample size $n$ increases.|
|**Zone Map**|Lightweight metadata stored per data block containing the minimum and maximum column values, enabling exact block-skipping without reading raw data.|
|**Reservoir Sampling**|An incremental algorithm maintaining a fixed-size sample of size $k$ over an uncounted data stream, guaranteeing a uniform random sample at every point.|
|**Stratified Sampling**|A technique partitioning skewed populations into homogeneous subgroups (strata) and sampling each separately to ensure rare, high-value items are represented.|
|**Analytical Bootstrap**|Closed-form statistical formulas (such as $SE = s/\sqrt{n}$) used to compute sampling distributions directly without requiring computational resampling iterations.|
|**Sketches**|Sub-linear space, single-pass probabilistic data structures (e.g., HyperLogLog, Count-Min) used for aggregates where sampling fails, such as distinct counts and frequency bounds.|
