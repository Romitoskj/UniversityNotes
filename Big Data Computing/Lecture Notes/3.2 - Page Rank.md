Section 1: Detailed Module Summary

1. Link Analysis & Search Architecture

Modern web search engines separate document evaluation into two distinct components:

1. **Online / Query-Dependent Relevance (**$S_{\text{text}}(q, d)$**):** Evaluates how well a web page matches a specific text query $q$ using an inverted index.
2. **Offline / Query-Independent Authority (**$P(d)$**):** Evaluates the intrinsic importance of a web page $d$ based strictly on the hyperlink structure of the web graph, independent of any user query.

The final score assigned to a document $d$ for a query $q$ is governed by a linear combination hyperparameter $\alpha \in [0, 1]$: $$\text{Score}(q, d) = \alpha \cdot S_{\text{text}}(q, d) + (1 - \alpha) \cdot P(d)$$

- If $\alpha = 1$, ranking depends purely on text matching, ignoring link structure.
- If $\alpha = 0$, ranking depends purely on offline structural authority.
- Tuning $\alpha$ (typically around $0.5$) balances textual match quality with global authority.

2. Core Intuitions of PageRank

Introduced in 1998 by Sergey Brin and Larry Page (_"The Anatomy of a Large-Scale Hypertextual Web Search Engine"_), PageRank leverages the structural topology of the web—a scale-free network containing a small number of massive hub nodes and a vast majority of nodes with very few in-links.

PageRank operates on two core intuitions:

- **Intuition 1 (Links as Votes):** A directed link from page $u$ to page $v$ constitutes an endorsement or vote by $u$ for $v$. The more incoming links (in-degree) a page receives, the more important it is.
- **Intuition 2 (Recursive Importance / Weighted Votes):** Votes from important pages carry higher weight than votes from obscure pages. A page is important if important pages point to it.

```
[Famous Page U]  ====(Heavy Weight Vote)====>  [Page V]
[Obscure Page]   ----(Light Weight Vote)---->  [Page V]
```

3. Mathematical Formulations

A. The Flow Model Equations

Let $(V, E)$ be the web graph with $N = |V|$ nodes.

- $O_v$: set of pages that $v$ links to (out-links).
- $o_v = |O_v|$: out-degree of page $v$.
- $I_v$: set of pages that link to $v$ (in-links).
- $r_v$: rank (importance score) of page $v$.

Under the basic flow model:

1. A page splits its total rank $r_u$ equally among all its out-links. Each out-link carries a share equal to $\frac{r_u}{o_u}$.
2. A page's total rank $r_v$ is the sum of the shares received from all its in-linking pages: $$r_v = \sum_{w \in I_v} \frac{r_w}{o_w}$$

Because the system of flow equations fixes only the relative proportions between ranks, it has infinitely many scalar-multiple solutions. To pin down a unique scale, the system is constrained so that the sum of all ranks equals 1: $$\sum_{v \in V} r_v = 1$$

Directly solving this system using Gaussian elimination is computationally infeasible at web scale (where $N$ reaches hundreds of billions of equations).

B. Linear Algebra Formulation & Eigenvector Model

The web graph is represented by an $N \times N$ column-stochastic transition matrix $M$: $$M_{vw} = \begin{cases} \frac{1}{o_w} & \text{if } w \text{ links to } v \\ 0 & \text{otherwise} \end{cases}$$

Every column of $M$ sums to 1. The flow equations can be expressed compactly in matrix-vector form: $$M r = r$$

This reveals that the PageRank vector $r$ is an **eigenvector** of matrix $M$ corresponding to the eigenvalue $\lambda = 1$. Because $M$ is column-stochastic, its largest eigenvalue is $\lambda_1 = 1$, making $r$ the **principal eigenvector** of $M$.

C. Power Iteration Algorithm

To find $r$ at scale, an iterative numerical method called **Power Iteration** is used:

1. Initialize rank vector $r^{(0)} = \left[ \frac{1}{N}, \frac{1}{N}, \dots, \frac{1}{N} \right]^T$ (assigning uniform rank to all pages).
2. Iteratively update: $r^{(t+1)} = M \cdot r^{(t)}$.
3. Terminate when $\|r^{(t+1)} - r^{(t)}\| < \epsilon$, where $\epsilon$ is a predefined stopping tolerance.

D. Probabilistic View (The Random Surfer & Markov Chains)

PageRank can also be modeled as a **Random Surfer** navigating the web graph forever:

- At any step, the surfer selects an outgoing link from the current page uniformly at random with probability $\frac{1}{o_w}$.
- This process forms a **Markov Chain**, which possesses the **Markov Property**: the probability of transitioning to the next state depends _only_ on the current state, not on the historical sequence of preceding states.
- The transition matrix $M$ represents the transition probabilities $P(\text{next} = v \mid \text{current} = w)$.
- The PageRank vector $r^*$ represents the **stationary distribution** $p^*$ of the Markov chain—the long-run fraction of time the random surfer spends on each web page.

4. Graph Structural Problems and Google's Fixes

To guarantee that Power Iteration converges to a unique stationary distribution, the transition matrix must satisfy the **Perron-Frobenius Theorem**.

Perron-Frobenius Theorem

If an $N \times N$ matrix $A$ is column-stochastic and **strictly positive** ($A_{ij} > 0$ for all $i, j$), then:

1. $\lambda_1 = 1$ is the principal eigenvalue, and all other eigenvalues have $|\lambda_i| < 1$.
2. The eigenspace for $\lambda_1 = 1$ has dimension 1.
3. There exists a unique strictly positive eigenvector $r^*$ whose components sum to 1.
4. Power iteration $r^{(t+1)} = A r^{(t)}$ converges to $r^*$ from _any_ initial probability vector $r^{(0)}$.

Real-world web graphs violate the strictly positive assumption (matrices are highly sparse) and exhibit two structural pathologies:

|Problem|Structural Cause|Algebraic Effect|Fix|
|---|---|---|---|
|**Dead Ends**|Pages with no outgoing links ($o_v = 0$).|The matrix column for $v$ is all zeros. $M$ is no longer column-stochastic. Total rank leaks out and the rank vector vanishes to $\mathbf{0}$.|**Dead-End Teleportation:** Replace all-zero columns with a uniform column vector $\left[\frac{1}{N}\right]^T$. The surfer jumps to any random page with probability $\frac{1}{N}$.|
|**Spider Traps**|A set of pages with links that form a closed loop with no out-links leading outside the group.|$M$ remains column-stochastic but is not strictly positive. Rank enters the loop but cannot leave, absorbing 100% of graph rank and causing vector oscillation.|**Global Teleportation (Damping Factor** $d$**):** At every step, the surfer follows a link with probability $d$ (typically $d = 0.85$) or teleports to a random page with probability $1 - d$.|

```
Dead End:    [ Node Y ] ---> [ Node Z (No Out-Links) ]  ==>(Rank Leaks Out to 0)==>  Ø
Spider Trap: [ Node V ] ---> [ Loop: W <---> X ]        ==>(Rank Absorbed 100%)==>  [ Loop Holds All Rank ]
```

The Google Matrix ($G$)

Combining both fixes yields the **Google Matrix** $G$: $$G = d M + \frac{1 - d}{N} \mathbf{1} \mathbf{1}^T$$ where $\mathbf{1}$ is an $N \times 1$ vector of all ones. Matrix $G$ is column-stochastic and strictly positive ($G_{ij} > 0$), satisfying all Perron-Frobenius conditions and guaranteeing a unique PageRank vector $r^*$.

5. Computing PageRank at Scale

Sparse Iteration Algorithm

Constructing $G$ directly is impossible at web scale because $G$ is dense. For $N = 10^9$ pages, storing $G$ (with 4 bytes per cell) requires approximately **4 Exabytes (EB)** of memory. Storing only real links in a sparse matrix $M_{\text{link}}$ requires only about **80 Gigabytes (GB)**.

To evaluate $r^{(t+1)} = G r^{(t)}$ without materializing $G$, the computation is decoupled into sparse link matrix multiplication and a scalar re-insertion constant: $$r^{(t+1)} = d \cdot M_{\text{link}} r^{(t)} + \frac{1 - S}{N} \mathbf{1}$$ where $S = \sum_{v \in V} (d \cdot M_{\text{link}} r^{(t)})_v$ represents the total rank retained along structural links. The term $\frac{1 - S}{N}$ re-inserts both global teleportation rank and rank lost to dead ends in a single step.

Convergence Rate & Iteration Count

The convergence rate of power iteration on the Google matrix is bounded by the damping factor $d$: $$\|r^{(t)} - r^*\|_1 \le 2 \cdot d^t$$

- For $d = 0.85$ and tolerance $\epsilon = 10^{-6}$, power iteration reaches convergence in approximately **90 iterations**.
- For $d = 0.95$, it requires approximately **1444 iterations**.
- Crucially, the convergence rate is **independent of graph size** $N$.

Parallel Frameworks: MapReduce vs. Spark

- **MapReduce:** Each power iteration consists of a Map step (emits rank shares $d \cdot \frac{r_w}{o_w}$ to target pages), a Shuffle step (groups shares by target page), and a Reduce step (sums incoming rank). Because MapReduce cannot persist state across jobs, the web graph structure and intermediate ranks must be written to HDFS disk and re-read at every iteration, resulting in high I/O overhead.
- **Apache Spark:** Solves MapReduce I/O bottlenecks by calling `.cache()` on the adjacency graph `links` in main memory. The graph structure is read from disk once, and iterations execute rapidly in-memory over updating `ranks` RDDs.

6. Summary of PageRank Variants & Related Algorithms

```
                       ┌───────────────────────────────┐
                       │     Link Analysis Suite       │
                       └──────────────┬────────────────┘
                                      │
         ┌────────────────────────────┴────────────────────────────┐
         ▼                                                         ▼
┌─────────────────────────────────┐                       ┌──────────────────────────────────┐
│ Global / Query-Independent      │                       │ Local / Query-Dependent          │
└────────────────┬────────────────┘                       └────────────────┬─────────────────┘
                 │                                                         │
   ┌─────────────┴─────────────┐                                           │
   ▼                           ▼                                           ▼
┌───────────────────┐ ┌───────────────────┐                       ┌──────────────────┐
│ Standard PageRank │ │ Personalized PR   │                       │ HITS Algorithm   │
│ Teleport: Uniform │ │ Teleport: Target  │                       │ Hubs & Authority │
│ 1/N to all pages  │ │ Node v or Set S   │                       │ Scores on Subset │
└───────────────────┘ └───────────────────┘                       └──────────────────┘
```

- **Personalized PageRank:** Modifies the teleportation vector so the surfer jumps exclusively to a target node $v$ (or set of nodes $S$) rather than uniformly across $V$. Used for recommendation systems, topic-sensitive ranking, and finding related pages.
- **Monte Carlo PageRank:** Approximates PageRank by simulating $R$ independent random walks that terminate with probability $1 - d$. The histogram of stopping pages approximates $r^*$. It is embarrassingly parallel with approximation error shrinking at a rate of $O(1/\sqrt{R})$.
- **HITS (Hubs and Authorities):** Developed by Jon Kleinberg (1999). Computes two scores per page on a small, query-dependent subgraph:
    - **Authority Score (**$a_v$**):** Measures page content value; pointed to by good hubs.
    - **Hub Score (**$h_v$**):** Measures page link directory value; points to good authorities.
    - Mutually reinforced updates: $a_v = \sum_{w \in I_v} h_w$ and $h_v = \sum_{u \in O_v} a_u$ (normalized each iteration).

1. **Answer:** The final score combines an online, query-dependent text relevance score $S_{\text{text}}(q, d)$ with an offline, query-independent authority score $P(d)$ using a hyperparameter $\alpha \in [0, 1]$. The overall rank is computed as $\text{Score} = \alpha \cdot S_{\text{text}}(q, d) + (1 - \alpha) \cdot P(d)$. Adjusting $\alpha$ determines whether search results prioritize textual match precision or global structural importance.
2. **Answer:** The first intuition treats directed hyperlinks as votes, meaning pages with more incoming links are deemed more important. The second intuition asserts that votes from important pages carry greater weight than votes from obscure pages. Together, these form a recursive definition where a page's importance is determined by the importance of the pages linking to it.
3. **Answer:** The basic flow equations are linearly dependent and only fix the relative proportions between page ranks rather than absolute values. Substituting one equation into another reduces the system to redundant statements, allowing any scalar multiple of a solution vector to satisfy the system. To establish a unique solution, the constraint $\sum_{v \in V} r_v = 1$ must be enforced.
4. **Answer:** A column-stochastic matrix is a non-negative square matrix in which the entries in each column sum to 1. In PageRank, the transition matrix $M$ is constructed column-stochastic by setting entry $M_{vw} = 1/o_w$ if page $w$ links to $v$. This ensures that every page distributes exactly 100% of its rank to its out-neighbors, making the rank vector an eigenvector corresponding to eigenvalue $\lambda = 1$.
5. **Answer:** The Markov Property states that the probability of transitioning to the next state depends exclusively on the current state and is independent of prior history. For the Random Surfer, the choice of the next page depends only on the outgoing links of the page currently being visited. The historical sequence of pages traversed to reach the current page plays no role in calculating transition probabilities.
6. **Answer:** A dead end is a page or node that possesses no outgoing links ($o_v = 0$). In the transition matrix, a dead end creates an all-zero column, violating column-stochasticity. As a result, rank leaks out of the system during power iteration, causing all entries in the rank vector to vanish to zero.
7. **Answer:** A spider trap is a set of nodes with links that form a closed loop, allowing rank to enter but never leave. The damping factor $d$ (typically set to 0.85) ensures that at each step, the surfer follows graph links with probability $d$ and teleports to a random web page with probability $1 - d$. This uniform random jump gives the surfer a non-zero probability of escaping the trap at every step.
8. **Answer:** The full Google matrix $G = d M + \frac{1-d}{N} \mathbf{1}\mathbf{1}^T$ replaces zero entries with positive fractions, making it dense. For $N = 10^9$ pages, storing $G$ directly would require roughly 4 Exabytes of memory. Instead, computations use the sparse link matrix $M_{\text{link}}$ (~80 GB) and account for dense teleportation algebraically using a single scalar addition constant $\frac{1-S}{N}$.
9. **Answer:** MapReduce must write the link structure and intermediate rank vectors to HDFS disk at the end of every iteration and re-read them at the start of the next, causing massive I/O overhead. Apache Spark caches the static link graph in main memory once using `.cache()` and performs power iteration steps in memory across updating rank RDDs, drastically reducing execution time.
10. **Answer:** PageRank computes a single, global, query-independent authority score for every page across the entire web graph at crawl time. In contrast, HITS is computed online at query time on a small, query-dependent subgraph (a base set of matching pages and their immediate neighbors). Furthermore, HITS calculates two distinct scores per node—Hubs and Authorities—rather than a single PageRank score.

Section 5: Comprehensive Glossary

- **Authority Score (**$a_v$**):** In the HITS algorithm, a numerical score measuring the quality of a page's actual content; high authority scores are assigned to pages pointed to by many strong hubs.
- **Column-Stochastic Matrix:** A square matrix with non-negative real entries where the values in each column sum to 1, representing valid transition probability distributions.
- **Damping Factor (**$d$**):** A scalar hyperparameter (typically set to $0.85$) representing the probability that a random surfer continues following graph links rather than teleporting.
- **Dead End:** A node in a directed graph that contains no outgoing edges ($o_v = 0$), causing rank leakage during iterative multiplication.
- **Eigenvector / Eigenvalue:** A non-zero vector $r$ that changes only by a scalar factor $\lambda$ when a linear transformation matrix $M$ is applied ($M r = \lambda r$). For PageRank, $r$ is the principal eigenvector with $\lambda = 1$.
- **Flow Model:** A structural formulation of PageRank where each node evenly splits its total rank among its out-links and receives rank equal to the sum of incoming shares.
- **Google Matrix (**$G$**):** The dense, strictly positive, column-stochastic matrix $G = d M + \frac{1-d}{N} \mathbf{1}\mathbf{1}^T$ created by combining the structural transition matrix with dead-end and global teleportation mechanisms.
- **HITS Algorithm:** "Hyperlink-Induced Topic Search," a query-dependent link analysis algorithm developed by Jon Kleinberg that computes dual Hub and Authority scores on localized subgraphs.
- **Hub Score (**$h_v$**):** In the HITS algorithm, a numerical score measuring a page's value as a directory or catalog; high hub scores are assigned to pages that point to many strong authorities.
- **In-Degree (**$I_v$**):** The set or count of incoming directed edges pointing toward a node $v$ in a graph.
- **Markov Chain:** A discrete-time stochastic process over a set of states satisfying the Markov Property, governed by a transition matrix.
- **Markov Property:** The memoryless property of a stochastic process specifying that future state transitions depend exclusively on the current state.
- **Monte Carlo PageRank:** An approximation method for PageRank that simulates $R$ independent finite random walks and constructs a rank histogram from their stopping locations.
- **Out-Degree (**$o_v$**):** The number of outgoing directed edges originating from a node $v$.
- **PageRank (**$P(d)$ **/** $r_v$**):** A query-independent score measuring the intrinsic structural authority of a web page based on the stationary distribution of a random walk.
- **Perron-Frobenius Theorem:** A fundamental theorem in linear algebra establishing conditions (column-stochasticity and strict positivity) under which a matrix possesses a unique, positive principal eigenvector with eigenvalue 1 to which power iteration converges.
- **Personalized PageRank:** A variant of PageRank where the teleportation distribution is concentrated on a specific node or subset of nodes rather than distributed uniformly across all pages.
- **Power Iteration:** An iterative numerical algorithm that computes the principal eigenvector of a matrix by repeatedly multiplying an initial vector by the matrix ($r^{(t+1)} = M r^{(t)}$).
- **Random Surfer Model:** A probabilistic conceptualization of PageRank modeling an internet user randomly traversing outgoing links or jumping to new pages.
- **Scale-Free Network:** A network topology whose degree distribution follows a power law, characterized by a small number of highly connected hub nodes and a long tail of sparsely connected nodes.
- **Spider Trap:** A set of nodes in a directed graph containing internal links but no edges pointing outside the set, causing unmitigated rank accumulation during power iteration.
- **Stationary Distribution (**$p^*$**):** The long-run probability distribution over the states of a Markov chain that remains invariant after multiplication by the transition matrix ($M p^* = p^*$).
- **Teleportation:** An artificial transition mechanism that allows a random surfer to jump to a page uniformly or non-uniformly at random, bypassing structural dead ends and spider traps.
